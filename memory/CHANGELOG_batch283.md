# Changelog — BUILD 283 (2026-06-13)

## NEW MODULE: Insurance Claims (documentation & reporting)
A complete, theme-aware module to document insurable losses and generate
professional insurance PDF reports. Free feature, separate from Warranty Claims.
Entry point: Vault/More tab → "Insurance Claims" (below Data Management).

### Backend — `backend/insurance_claims.py` (wired in server.py via make_insurance_claims_router)
- Collections (user-scoped): `insurance_claims` (core + embedded items/notes/timeline/
  status_history), `claim_evidence` (claim-only photos/docs, base64), `claim_reports`
  (immutable generated PDF versions, base64).
- Endpoints: spec, summary (6 stat aggregates), list (q/status/claim_type/archived,
  sort), CRUD, status change (logs timeline + status_history), attach items (bulk),
  patch item (conditions + value overrides), single detach + bulk-remove, notes
  add/delete, evidence add/list/get/delete, duplicate, archive toggle, reports
  render (quick|detailed → PDF), report list/download, report email (Gmail + PDF attach).
- PDF engine reuses ReportLab helpers from reports.py. Professional insurance template:
  brand header, claimant + claim meta, insurance/policy, incident, itemized assets,
  live financial totals, timeline, notes, photo/receipt pages, claim-evidence pages.
  Footer stamps Claim#/Policy#/version/date-time/page#, "Generated by Toolbox Vault".
- Data integrity: claims REFERENCE inventory (tool_id + snapshot fallback) and never
  modify/delete tools; generated PDFs are frozen blobs; net_claimed clamped to
  coverage_limit and ≥0.

### Frontend — `app/insurance-claims/` (index, new, [id]) + `src/insuranceApi.ts`,
###   `src/insuranceReport.ts`, `src/components/insurance/ICKit.tsx`
- Dashboard: 6 summary cards, search, status filter chips, archived view, claim list.
- Create/Edit form: all claim + insurance + financial fields, "Import from Profile".
- Detail: status changer, live financial totals, insurance card, attached items
  (attach modal w/ search + select-visible, per-item condition/value edit, remove),
  claim evidence (photo via expo-image-picker, document via expo-document-picker, base64),
  notes, timeline, reports (generate quick/detailed w/ section include toggles, history
  list with view/share/email).
- Fully theme-aware (light/dark/industrial skin) via SkinPlate + useColors + themedStyles.
